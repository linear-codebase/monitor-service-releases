# Monitor de Entregas — releases

Instaladores e atualizações do **Monitor de Entregas**, o painel de entregas exibido na TV do quiosque.

O código fica no repositório privado; este repositório público só hospeda as releases (instalador Windows, assinaturas e `latest.json`), para que os quiosques instalados consigam se atualizar sozinhos.

## Instalar

1. Baixe o `Monitor.de.Entregas_<versão>_x64-setup.exe` da [release mais recente](https://github.com/linear-codebase/monitor-service-releases/releases/latest).
2. Execute. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
3. O app abre em tela cheia, inicia com o Windows e se atualiza automaticamente.
